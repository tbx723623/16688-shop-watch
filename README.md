# 16688 店铺轮询脚本

16688 店铺「派大星（5000人群）」（店铺号 S226658）的对接商品状态轮询脚本。
每 10 分钟跑一轮，只读核对，不改商品、不改价格、不下单。

## 它做什么

- `check_api_1400.py`：2026-11-20 14:00 轮实际跑过的脚本原文。标准库
  Python 3，无第三方依赖，无需登录。
- 每轮 POST `https://www.16688.com.cn/shopApi/goods/detail`，
  按 `goods_no` 逐件查约 114 件对接商品的名称、售价、卡密库存、
  库存状态、发货方式、店铺号和销量，写进 `check_api_<时间>.jsonl`。
- `sample_run_1400.jsonl`：同一轮的真实运行日志节选。

## 运行方式

```bash
python3 check_api_1400.py
```

输出写到 `~/workspace/shop-watch/check_api_<时间>.jsonl`，每行一件商品。
接口对已下架或开关关闭的商品会返回 `{"code": 0, "msg": "商品不存在"}`，
须用浏览器后台复核才能定性，不可单凭接口结论下架。
